# Coleccion Bruno

Abre en Bruno la carpeta:

```text
bruno/Prueba Tecnica Fullstack
```

Selecciona el environment `Local` y ejecuta en este orden:

1. `Login`
2. `Create Number`
3. `List Numbers`
4. `Get Number By Id`
5. `Update Number`
6. `Get Stats`
7. `Delete Number`
8. `Logout`

El request `Login` guarda automaticamente `access_token` y `refresh_token`.
El request `Create Number` guarda automaticamente `number_id` para reutilizarlo en los endpoints por ID.
